# Retired Stage-4 matrix

The pooled-versus-heterogeneous matrix is retired. This worktree supports only
heterogeneous native models. Its old base config and split manifest are removed.

Use `configs/campaigns/ablation_default_v1.yaml` for current paired interventions
and `workflow/config/mn5_crossval.yaml` for native source-set cross-validation.
The historical Stage-4 comparison script remains available to read complete old
16-condition result sets. It is not an execution plan for this worktree.
